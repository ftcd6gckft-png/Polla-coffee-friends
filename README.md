# ⚽ La Polla — Mundial 2026

Polla del Mundial 2026 con fixture real, horarios en hora Colombia, y tabla en tiempo real.

## Setup rápido

1. Instalar dependencias: `npm install`
2. Copiar `.env.example` como `.env.local` y llenar las variables de Firebase
3. Correr en local: `npm run dev`
4. Build para producción: `npm run build`
